# 🚀 SIH – Smart India Hackathon Project

A modern web application developed using React.js and Vite, featuring a multilingual resource structure with audio assets for multiple Indian languages.

---

## 📌 Project Overview

This project is developed as part of the Smart India Hackathon (SIH) initiative. It aims to provide an interactive and accessible web-based experience through a modern frontend application.

The application includes multilingual audio resources organized into separate language directories, supporting content accessibility across different Indian languages.

Built using React.js and Vite, the application provides a responsive frontend environment with optimized production builds.

## 🔄 Project Workflow

The application follows a structured workflow to provide an interactive multilingual experience.

### Step 1: User Access

The user accesses the application through a web browser.

### Step 2: Application Initialization

The React application initializes and loads the necessary components, interface elements, and static resources.

### Step 3: User Interaction

The user interacts with the available application features through the frontend interface.

### Step 4: Language Selection

The user selects an available language, where supported by the application.

### Step 5: Resource Loading

The application accesses the corresponding language-specific audio resources.

### Step 6: Audio Processing and Playback

The selected audio resource is loaded and presented through the application's audio interface.

### Step 7: Output

The user receives the requested content through the application interface.

## 🏗️ Project Architecture

The application follows a frontend-oriented architecture.

### Frontend Layer
React.js manages the user interface, components, and interactions.

### Development Layer
Vite provides the development server, Hot Module Replacement (HMR), and production build functionality.

### Resource Layer
Static assets and language-specific audio resources are organized into directories.

### Presentation Layer
HTML, CSS, and SVG resources support the visual presentation and graphical elements.

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

### Prerequisites

Make sure the following are installed:

- Node.js
- npm
- Visual Studio Code
- Git

### Step 1: Clone the Repository

```bash
git clone https://github.com/Kavi-Anand/SIH-Project.git
```

### Step 2: Navigate to the Project Directory

```bash
cd SIH-Project
```

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Start the Development Server

```bash
npm run dev
```

### Step 5: Open the Application

Open the localhost URL displayed in the terminal.

Usually:

```text
http://localhost:5173
```

---

## 🏭 Production Build

To generate an optimized production build, execute:

```bash
npm run build
```

The generated production files will be available inside the `dist/` directory.

### Preview Production Build

```bash
npm run preview
```
